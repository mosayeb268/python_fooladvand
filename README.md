## 🌟 ویژگی‌های کلیدی پروژه (Key Features)

### ۱. 🐍 موتور پیشرفته و حرفه‌ای پایتون (Pyodide WebAssembly Core)
- **اجرای واقعی کدهای پایتون در مرورگر:** بدون نیاز به نصب هیچ‌گونه نرم‌افزار اضافی یا سرور بک‌اند؛ پردازش به صورت امن داخل کلاینت انجام می‌شود.
- **پشتیبانی کامل از کتابخانه‌های علم داده:** بسته‌های **NumPy**، **Pandas** و **SciPy** به صورت خودکار یا در پس‌زمینه بارگذاری می‌شوند.
- **نمایش و رسم نمودارها (Matplotlib):** نمودارهای ترسیم‌شده به صورت خودکار رهگیری شده و تصاویر گرافیکی باکیفیت در کنسول نمایش داده می‌شوند.
- **فایل‌سیستم مجازی پیش‌بارگذاری‌شده (Virtual FS):** دیتاست‌های واقعی دوره (`16-Employees.csv` و `21-titanic.csv`) و ماژول‌های کمکی (`m1.py`) در حافظه مجازی قرار دارند؛ بنابراین کدهای `pd.read_csv('16-Employees.csv')` بدون خطا اجرا می‌شوند.
- **شبیه‌ساز ورودی تعاملی (`input()`):** پشتیبانی از دریافت چند ورودی متوالی و بازتاب متنی آن‌ها همانند ترمینال‌های واقعی.

### ۲. 📱 بهینه‌سازی ویژه برای تبلت شیائومی Xiaomi Pad 6 Pro
- **سازگاری با نمایشگر ۱۱ اینچ با رزولوشن 2880x1800 (16:10):** چیدمان منعطف با فونت شفاف وزیرمتن و فونت کدهای JetBrains Mono.
- **حالت دو ستونه (Split View / Docked IDE):** امکان داک کردن محیط کدنویسی در کنار متن جزوه جهت مطالعه و کدنویسی هم‌زمان بدون پوشاندن متن.
- **پشتیبانی از کیبورد سخت‌افزاری تبلت:** کلید میانبر **`Ctrl + Enter`** برای اجرای سریع کدها بدون نیاز به لمس صفحه.
- **پشتیبانی کامل از PWA و اجرای آفلاین:** امکان نصب مستقیم به عنوان اپلیکیشن مستقل با قابلیت کش خودکار از طریق Service Worker.
- **آمادگی کامل برای تولید فایل نصبی APK:** پیکربندی یکپارچه با Capacitor جهت ساخت خروجی بومی اندروید در Android Studio.

### ۳. 📖 ساختار محتوایی منسجم (۲۱ قلم آموزشی در ۷ فصل)
- **فصل ۰: مقدمه و مراجع:** مرجع وس مک‌کینی (Python for Data Analysis) و مراجع رسمی (اقلام ۰۱ و ۰۲).
- **فصل ۱: مبانی پایتون و ساختارهای شرطی:** عملگرها، انواع داده‌ها، متغیرها و کدهای ۱-۱ تا ۱-۹ (اقلام ۰۳ و ۰۵).
- **فصل ۲: ساختارهای داده و توالی‌ها:** لیست، تاپل، دیکشنری، مجموعه، حلقه‌ها و کدهای ۲-۱ تا ۲-۱۱ (اقلام ۰۴ و ۰۶).
- **فصل ۳: توابع و ماژول‌ها:** `*args` و `**kwargs`، توابع بازگشتی، ماژول `m1.py` و کدهای ۳-۱ تا ۴-۵ (اقلام ۰۷ تا ۰۹).
- **فصل ۴: محاسبات ماتریسی با NumPy:** آرایه‌های ndarray، ابعاد، برودکستینگ و نوت‌بوک‌های ۱۱ و ۱۳ با امکان اجرای زنده سلول‌ها (اقلام ۱۰ تا ۱۳).
- **فصل ۵: کاوش و مهندسی داده با Pandas:** ساختارهای Series و DataFrame، فیلترها، `loc` و `iloc` و نوت‌بوک ۱۵ (اقلام ۱۴ تا ۱۷).
- **فصل ۶: کار با داده‌های واقعی:** تحلیل دیتاست کارکنان (`Employees.csv`) و مسافران تایتانیک (`titanic.csv`) همراه با جداول کاوشگر و نوت‌بوک ۱۸ (اقلام ۱۶ تا ۲۱).
- **فصل ۷: خودآزمایی و آزمون تستی استاندارد:** سوالات چهارگزینه‌ای همراه با فیدبک و امتیازدهی لحظه‌ای.

## 🚀 راهنمای نصب و اجرا

### الف) اجرای سریع روی سیستم محلی (ویندوز / مک / لینوکس)
1. **پیش‌نیاز:** نصب بودن [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر)
2. **اجرای آسان با یک کلیک:** دابل‌کلیک روی فایل `run_website.bat`
3. یا اجرای دستی در ترمینال:
```bash
cd website
npm install
npm run dev
```
آدرس مرورگر: 👉 `http://localhost:5173/` یا `http://localhost:4173/`

---

### ب) نصب روی تبلت شیائومی Xiaomi Pad 6 Pro

#### روش اول: نصب آنی به عنوان PWA (پیشنهادی - بدون نیاز به کابل و بیلد):
1. سایت را اجرا کنید (روی کامپیوتر یا دیپلوی رایگان گیت‌هاب).
2. در تبلت با مرورگر Chrome یا Mi Browser آدرس را باز کنید.
3. روی منوی سه نقطه کلیک کرده و گزینه **Add to Home screen** یا **Install app** را بزنید.
4. آیکون برنامه به صفحه تبلت اضافه می‌شود و از این پس به صورت فول‌اسکرین و بدون نوار آدرس مرورگر کار خواهد کرد.

#### روش دوم: ساخت فایل نصبی مستقل APK (با Capacitor):
1. اجرای فایل اسکریپت آماده: `build_android.bat`
2. یا اجرای دستی دستورات زیر:
```bash
cd website
npm run build
npx @capacitor/cli add android
npx @capacitor/cli sync android
npx @capacitor/cli open android
```
3. در نرم‌افزار Android Studio از منوی `Build` گزینه `Build APK(s)` را بزنید تا فایل `.apk` برای تبلت آماده شود.

## 🌐 استقرار خودکار روی GitHub Pages

پروژه به همراه گردش‌کار اختصاصی GitHub Actions در مسیر `.github/workflows/deploy.yml` پیکربندی شده است:
1. ایجاد مخزن جدید در گیت‌هاب و ارسال کدها:
```bash
git add .
git commit -m "feat: upgrade python engine, tablet optimizations and ready for github"
git remote add origin https://github.com/<نام-کاربری>/<نام-مخزن>.git
git push -u origin main
```
2. در تنظیمات مخزن گیت‌هاب (Settings > Pages)، منبع انتشار (Source) را روی **GitHub Actions** بگذارید.
3. سایت بلافاصله روی دامنه رایگان گیت‌هاب آنلاین شده و از هر دستگاهی در دسترس خواهد بود.
